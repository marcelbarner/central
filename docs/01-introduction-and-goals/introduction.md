# Introduction and Goals

## Requirements Overview

Central is a web application built with a hexagonal architecture pattern, providing a RESTful API backend and an Angular frontend.

### Key Features

* RESTful API endpoints using FastEndpoints
* Domain-driven design with clean separation of concerns
* PostgreSQL database for data persistence
* Cookie-based authentication with ASP.NET Core Identity
* API token and basic authentication support
* Local development support via Aspire

## Quality Goals

| Priority | Goal | Description |
|----------|------|-------------|
| 1 | Maintainability | Clean architecture with clear boundaries between layers |
| 2 | Testability | Comprehensive test coverage (≥80%) across all layers |
| 3 | Performance | Efficient data access and minimal response times |
| 4 | Security | Secure authentication and authorization |

## Stakeholders

| Role | Expectations |
|------|-------------|
| Developers | Clean, maintainable codebase with clear patterns |
| Users | Fast, reliable API responses |
| Operations | Easy deployment and monitoring |
